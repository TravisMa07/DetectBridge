# Original synthetic Windows fixtures

These XML events were authored for DetectBridge under Apache-2.0. They contain no
copied public telemetry, real host identities, imported rules or record labels.
Literal semantic expectations and their rationales were recorded before adapter
implementation in [the design](../../../docs/p11-design.md). Java cases mutate
these originals to test boundaries; they do not use evaluator output as an oracle.
